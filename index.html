Advexp.Settings

Cross-platform app settings and configurations for Python and .NET projects.

One settings API, two editions: a mature library for .NET available on NuGet and a Python port on PyPI.

Advexp.Settings for .NET

Cross-platform .NET app settings and configuration library. Saves settings locally in the native format of each platform: .NET Framework, .NET Core, .NET Standard and UWP. Open source, Apache-2.0 license.

Advexp.Settings.Local on NuGet

Advexp.Settings for Python

Python port of the Advexp.Settings library, in active development.
Python 3.9+, OS independent, Apache-2.0 license.

advexp-settings on PyPI

Our Features

.NET edition

  • .NET Framework, .NET Core, .NET Standard, UWP
  • Configure your app by using the Microsoft.Extensions.Configuration library

Python edition

  • Same settings API as the .NET edition
  • Python 3.9+, OS independent

Both editions

  • Save settings locally in the native format of each platform
  • Use any built-in or user-defined type as a setting
  • Save and load settings as dynamic parameters (name - value pairs)
  • Open source core under the Apache-2.0 license
